# Best evolved genotypes

`best_phase1.gen` holds the best run of every task × encoding × algorithm combination from
Phase 1 (72 creatures), in Framsticks' `.gen` format. Open it in Framsticks with
**File → Open…**. Names follow *task, encoding, algorithm, fitness, run*.

Task codes: `line` straight line, `sine` sinusoid bounce, `vel` forward velocity, `jump` jump
height, `dist` distance (organisers' function 3), `tall` tall runner (organisers' function 4).
